# 🍎 接水果大作战

一个使用 Vue 3 + Vite + TypeScript 构建的趣味接水果小游戏，纯前端实现，无需后端服务。

## ✨ 游戏特性

### 🎮 核心玩法
- **多种水果随机掉落**：苹果、橙子、草莓、葡萄、西瓜
- **炸弹躲避机制**：15% 概率掉落炸弹，碰到减 1 生命
- **篮子控制**：接住水果获得分数，躲避炸弹保持生命

### 🕹️ 多端控制
- **🖱️ 鼠标控制**：移动鼠标控制篮子左右移动
- **⌨️ 键盘控制**：方向键 ←→ 或 A/D 键
- **📱 触摸控制**：移动端滑动控制
- **⏸️ 暂停功能**：空格键或 ESC 键暂停/继续

### 🔥 连击系统
- **3连击** → 1.5x 加分
- **5连击** → 2x 加分
- **10连击** → 2.5x 加分
- **15连击** → 3x 加分
- **20+连击** → 4x 加分

### 📈 渐进难度
- 每接住 10 个水果提升 1 个关卡
- 水果掉落速度随关卡加快
- 生成频率随关卡提高

### 🎨 精美界面
- Canvas 绘制蓝天白云背景
- 木质纹理篮子
- 连击动画和分数弹出效果
- 开始/暂停/结束界面

## 🛠️ 技术栈

| 技术 | 说明 |
|------|------|
| **Vue 3** | 渐进式 JavaScript 框架 |

## 🎯 游戏说明

### 水果分值
| 水果 | 分值 |
|------|------|
| 🍎 苹果 | 10 分 |
| 🍊 橙子 | 15 分 |
| 🍓 草莓 | 15 分 |
| 🍇 葡萄 | 20 分 |
| 🍉 西瓜 | 25 分 |
| 💣 炸弹 | -1 ❤️ |

### 游戏规则
1. 控制篮子接住掉落的水果获得分数
2. 连续接住水果触发连击，获得额外加分
3. 水果掉落地面或接住炸弹会重置连击
4. 被炸弹击中会失去一条生命
5. 生命值归零游戏结束
6. 接住水果越多，关卡越高，难度越大

## 📝 核心文件说明

### 游戏状态管理 - [game.ts](src/stores/game.ts)
- 分数、生命、连击、关卡等状态管理
- 连击倍率计算
- 难度系数计算

### 数据生成器 - [mockData.ts](src/utils/mockData.ts)
- 使用 Mock.js 随机生成水果
- 配置水果类型、颜色、分值
- 随机生成位置、速度、旋转

### 游戏画布 - [GameCanvas.vue](src/components/GameCanvas.vue)
- Canvas 渲染游戏画面
- requestAnimationFrame 游戏循环
- 碰撞检测
- 鼠标/键盘/触摸事件处理

### HUD 界面 - [HUD.vue](src/components/HUD.vue)
- 实时显示分数
- 生命值爱心显示
- 连击和倍率显示
- 关卡显示

## 🔧 开发说明

### 添加新水果类型
1. 在 `mockData.ts` 的 `fruitTypes` 数组中添加新类型
2. 在 `fruitConfigs` 对象中配置水果信息
3. 更新开始界面的分值图例

### 调整难度
- 修改 `game.ts` 中的 `baseSpeed` 计算逻辑
- 修改 `game.ts` 中的 `spawnRate` 计算逻辑
- 调整 `mockData.ts` 中的炸弹生成概率

### 自定义样式
- 画布背景：修改 `GameCanvas.vue` 的 `drawBackground` 函数
- 篮子样式：修改 `GameCanvas.vue` 的 `drawBasket` 函数
- 界面配色：修改各组件的 `<style>` 部分
